# FastItemViewer — сравнение предметов при экипировке

Плагин показывает в инвентаре игрока, как изменится персонаж, если надеть предмет
(заменив текущий предмет в соответствующем слоте).

## Принятые решения

- Показывать **компактно на предмете** + **полную панель по наведению**.
- В первой версии сравнивать: жизнь, ману, ES, броню, уклонение, 4 резиста,
  силу/ловкость/интеллект, скорость передвижения, подавление магии, блок,
  а также DPS/APS/крит оружия.
- Для колец и оружия показывать **оба сравнения** (например, Ring1 и Ring2,
  Main Hand и Off Hand).
- В первую версию входит **только экипировка**: шлем, тело, перчатки, ботинки,
  пояс, амулет, кольца, оружие и оффхенд.
- Флаконы, джевелы, тинктуры и вторая пара оружия — позже.
- Подписи только на английском: HUD-шрифт не поддерживает кириллицу.
  Русские строки в интерфейсе плагина не используются.
- Плагин не заменяет PoB: считает вклад предмета и аддитивные итоги
  (резисты, жизнь, мана, атрибуты), а не полный пересчёт билда.

## Архитектура

- `FastItemViewer.cs` — вход плагина, `Tick`-кэш, `Render`, debug dump.
- `FastItemViewerSettings.cs` — настройки.
- `Items/EquipSlotMap.cs` — `ClassName` → слот экипировки.
- `Items/EquippedItems.cs` — чтение надетых предметов из `PlayerInventories`.
- `Items/PlayerContext.cs` — текущие статы игрока (жизнь, мана, ES, резисты, атрибуты).
- `Items/ItemSnapshot.cs` — снимок статов предмета.
- `Items/ItemStatsBuilder.cs` — `Mods.ItemMods` → `Dictionary<GameStat,int>`,
  защита, DPS, требования.
- `Items/StatCatalog.cs` — короткие подписи, приоритеты, веса, проекции.
- `Items/ItemComparisonEngine.cs` — выбор заменяемых слотов, дельты, score.
- `UI/ItemOverlayRenderer.cs` — компактный оверлей и панель по наведению.
- `UI/ItemDebugOverlay.cs` — debug-дамп статов предмета.

### Что уже реализовано

- `FastItemViewer.cs` — кэш сравнений, пересборка при изменении инвентаря/экипировки,
  debug dump по кнопке.
- `FastItemViewerSettings.cs` — включение, режимы отображения, цвета, шрифт,
  проекции резистов/жизни/маны/ES/атрибутов, debug.
  Отдельные настройки `DebugFontSize`, `DebugMaxWidth`, `HoverFontSize`,
  `HoverMaxWidth`.
- `Items/EquipSlotMap.cs` — классы предметов → слоты (включая двуручное оружие,
  луки, щиты, кольца и т.д.).
- `Items/EquippedItems.cs` — чтение надетых предметов из `PlayerInventories`.
- `Items/PlayerContext.cs` — текущие жизнь/мана/ES/резисты/атрибуты игрока.
- `Items/ItemSnapshot.cs`, `Items/ItemStatsBuilder.cs` — агрегация `Mods.ItemMods`
  по `GameStat`, защита, DPS, требования.
- `Items/StatCatalog.cs` — короткие подписи, приоритеты, веса, проекции,
  fallback-подписи из `Stats.dat`.
- `Items/ItemComparisonEngine.cs` — сравнение с надетым предметом, оба кольца,
  Main/Off Hand, учёт двуручного оружия и лука, score для рамки.
- `UI/ItemOverlayRenderer.cs` — текст на предмете и полная панель по наведению.
- `UI/ItemDebugOverlay.cs` — дамп `HumanStats`, модов, `GameStat`/`Key`/`UserFriendlyName`,
  `LocalStats`, защиты, DPS и требований.

### Как проверить

1. Включить плагин в списке плагинов HUD.
2. Открыть инвентарь. На экипируемых предметах должен появиться компактный блок
   с дельтами, вокруг предмета — цветная рамка.
3. Навести предмет — справа/слева от него появится полная панель с разбором
   по слотам и итоговыми резистами/жизнью.
4. Если подписи/цифры выглядят неверно, включить `Enable Debug Window`,
   навести предмет и посмотреть debug-дамп. Кнопка `Dump Hovered Item`
   выводит тот же дамп в лог HUD.
5. `Show Unknown Stats` включает показ всех незнакомых статов (может быть шумно).

### Результаты дампа из логов

- `base_maximum_life` → `BaseMaximumLife`, `base_maximum_mana` → `BaseMaximumMana` —
  совпадает с `StatCatalog`.
- `Mods.HumanStats` в этой сборке пустой, но `Mods.ItemMods` и `GameStat`
  работают, поэтому debug-дамп строится по `ItemMods` и агрегированным статам.
- Компонент `Armour` отдаёт ES предмета (например, `ES: 56`), поэтому для
  брони/щитов используется суммарная защита предмета, а не только моды.
- Неизвестные статы (`LocalAttributeRequirementsPct`,
  `EnergyShieldRechargeRatePct`, `BaseStunRecoveryPct`) не входят в key-stat
  набор; их можно увидеть через `Show Unknown Stats`.
- Кольцо `Ruby Ring`: `base_fire_damage_resistance_% -> BaseFireDamageResistancePct`
  и `additional_strength -> AdditionalStrength` — таблица совпадает.
- Оружие `Despot Axe`: DPS и APS считаются корректно; крит в `ItemStats`
  уже в процентах, поэтому умножение на 100 убрано.

## Заметки по реализации

- Текст рисуется через `Graphics.SetTextScale(...)` + `Graphics.DrawText(...)`,
  потому что перегрузка `DrawText(..., int height)` в этой сборке помечена
  `[Obsolete("Setting height is not supported")]`.
- Для колец и оружия строится несколько `SlotComparison` (Ring 1 / Ring 2,
  Main Hand / Off Hand), на предмете они показываются с префиксами `R1`, `R2`,
  `MH`, `OH`, `2H`.
- Проекция HP показывается только если у предмета нет разницы в `% maximum Life`;
  иначе вклад процентов не аддитивен с деревом пассивов.
- Debug-окно и панель по наведению используют `TextWrapper`: длинные строки
  переносятся по словам, слишком длинные токены — по символам.
- Размер шрифта debug-окна задаётся `DebugFontSize`, максимальная ширина —
  `DebugMaxWidth`. Для панели по наведению — `HoverFontSize` / `HoverMaxWidth`.
- Если один из слотов пуст (кольцо, оффхенд), компактный оверлей и цвет рамки
  используют именно пустой слот, чтобы не смешивать красные строки сравнения
  с занятым слотом. В hover-панели по-прежнему видны оба сравнения.
- В debug dump добавлены надетые кольца и список comparison targets со score,
  чтобы проверять, какой слот выбран.


## Ограничения

- Точный пересчёт билда (проценты, конверсии, капы, взаимодействия модов)
  не выполняется.
- DPS оружия — локальный DPS оружия, а не DPS билда.
- Для брони/ES показывается вклад предмета, а не полный пересчёт защиты персонажа.
